Privacy Policy for Satguru App

Last updated: May 2026

Satguru App is a mobile application that provides a simple dashboard and push notification service for users connected to the main Satguru website. This Privacy Policy explains how the app handles user information.

1. Information We Collect

Satguru App collects minimal information necessary to provide dashboard and notification functionality:

1.1 Account Information

  • Login credentials used for authentication
  • Basic profile details required to personalize the dashboard

1.2 Device Information

  • Device token used solely to deliver push notifications
  • Device type and OS version for compatibility purposes

All data is used strictly for providing app functionality and is not shared with third parties.

2. Permissions Used

2.1 Notifications

Used to send push notifications from the main Satguru website, including updates, announcements, and alerts relevant to the user. Notifications are only sent when there is relevant information to share.

3. Login and Authentication

The app requires users to log in to access the dashboard and receive personalized notifications. Authentication is handled securely and credentials are not shared with any third parties.

4. Data Sharing

Satguru App does not sell, share, or transfer any user data to third parties. The app connects to the main Satguru website solely to fetch dashboard content and deliver notifications. No external analytics or advertising services are used.

5. Children's Privacy

This app is not intended for children under 13. We do not knowingly collect data from children.

6. Data Security

We implement reasonable and appropriate security measures to protect user data handled by the app, including secure transmission (HTTPS) and access controls to prevent unauthorized access.

7. Changes to This Privacy Policy

We may update this Privacy Policy periodically. Updates will be posted on this page.
